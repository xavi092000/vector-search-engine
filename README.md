# Semantic Vector Search Experiments

Notebook-based experimentation with embeddings, Qdrant, and similarity retrieval.

## Scope and status

The implementation is [semantic_vector_search.ipynb](semantic_vector_search.ipynb). This is a learning and prototyping artifact, not a packaged search service or a production deployment.

## Review and reproduction

Review the notebook code and saved outputs on GitHub. Before executing it, inspect its package installation cells, Qdrant connection, model/API configuration, and data inputs. External services or model calls may incur charges. A locked environment, standalone installation command, and automated regression suite are not supplied in this snapshot.

Saved outputs are historical examples, not a current search-quality benchmark.
